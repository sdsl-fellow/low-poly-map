# 310관 지형·배치 재구성 근거

확인일: 2026-09-26. 이번 수정은 **Esri 위성영상 + OpenStreetMap 좌표 + 중앙대학교 공식 안내 + 설계자 제공 설명과 건축 사진**을 대조했다. Google Maps나 네이버 지도 화면을 직접 확인했다고 주장하지 않는다.

## 실제 확인한 자료

1. 위성영상: [Esri World Imagery](https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer).
   - 열람 영역: 경도 126.9534–126.9584, 위도 37.5016–37.5056. 1500×1500 영상.
   - 본체의 길고 굽은 윤곽, 동쪽 낮은 테라스, 서쪽 녹지, 주변 건물 배치를 대조했다.
   - 촬영일·수직 정확도는 확인되지 않았다. 높은 건물의 지붕은 촬영각에 의해 지상 윤곽에서 어긋날 수 있어 지붕 외곽을 그대로 바닥 충돌선으로 사용하지 않았다.
2. [OpenStreetMap 310관 윤곽](https://www.openstreetmap.org/way/607563318), 공개 지도 API에서 좌표 취득.
   - 주변 윤곽: 303관 `367405915`, 305관 `367405912`, 208관 `367405930`, 블루미르홀 `607563321`.
   - 상부 보행광장 `744062066`, 중간 보행공간 `744062067`, 하부 보행광장 `744062057`.
   - 계단 중심선 `744062068`, `744062055`; 교내 도로 `285364024`; 숲길 `946506419`.
   - `site-data.js`에 출처 ID, 건물 경위도 및 게임 좌표를 기록했다. 중심선 방향과 상대 위치를 임의의 직선 계단으로 바꾸지 않는다.
3. [중앙대학교 공식 캠퍼스맵](https://www.cau.ac.kr/cms/FR_CON/index.do?MENU_ID=610).
   - [공식 배치 이미지](https://www.cau.ac.kr/cau/img/about/caupusmap/map.png).
   - 건물 번호·명칭을 대조했다. 303 법학관, 305 교수연구동, 208 제2공학관, 308 블루미르홀, 310 100주년기념관.
4. [중앙대학교 영어교육과 출입 안내](https://englishedu.cau.ac.kr/?c=board&p=35&r=home&uid=576).
   - 1층 출입구의 **303관 방향**이라는 설명을 확인했다. 게임 입구는 이 방향의 상부 보행공간을 사용한다. 문짝의 정확한 위치·폭은 실측하지 않았다.
5. [Chung-Ang University 310 Hall — 건축문화/마실그라운드](https://masilground.com/158), 2017-06-21.
   - 설계자 간삼건축 제공 글, 사진 Lee Seungmu, 3장의 배치·단면 개념 스케치를 확인했다.
   - 도서관 후면·운동장·후문광장 세 레벨을 잇는 설계, 굽은 상층부, 중앙 아트리움, 기둥 아래 열린 공간, 석재와 유리 입면을 모델링에 반영했다.
6. [IOHSK 캠퍼스 사진](https://www.iohsk.net/conference-rooms).
   - 로비의 DONORS WALL, 상부 난간, 기둥과 재료 표현을 참고했다. 이 자료는 여러 캠퍼스 공간을 포함하므로 정확한 1층 평면 증거로 사용하지 않았다.

## 데이터와 해석의 경계

| 항목 | 반영 방식 |
|---|---|
| 310관 및 인접 건물 지상 윤곽 | OSM 경위도를 공통 좌표로 변환 |
| 교내 도로·계단 방향·보행광장 | OSM 중심선과 영역을 사용 |
| 위성영상 | 윤곽과 상대 배치·녹지·테라스 형태를 교차 확인 |
| 굽은 상층부와 창 배열 | 건축 사진을 보고 지상 윤곽 안에서 단순화 |
| 단차 | 설계 설명의 세 레벨을 96/48/0 렌더링 단위로 표현; 측량 높이가 아님 |
| 계단 폭·단수·접점 | 사진 및 게임 가독성에 맞춰 축약. 끝에 보행 여유를 추가 |
| 정원 내부 화단·나무·벤치 | 위치·개수는 추정 표현 |
| 주변 건물 높이 | 주건물을 가리지 않도록 낮추고 흐리게 표현; 외곽 위치는 지도 기준 |
| 실내 | 사진에 기반한 공간 분위기만 반영; 정확한 방·기둥 배치와 외부 연결은 임시 |

좌표 원점은 위도 37.50495 / 경도 126.9546. 게임 x는 남쪽, y는 동쪽이며 1 좌표 단위는 수평 약 8m이다. 입체 보기의 북쪽 화살표와 배치도 보기는 이 축을 공유한다. 수평 좌표와 화면 높이 축의 비율은 다르다. 실측 지도나 건물 길찾기 도구가 아니다.

## 저작권 및 데이터

- 지도 데이터: © OpenStreetMap contributors. [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). `site-data.js`의 지도 파생 데이터는 이 라이선스로 제공한다. 다른 코드 전체의 라이선스를 변경한다는 의미는 아니다.
- 위성영상·웹 사진은 관찰 자료로만 사용했으며 게임에 복제하거나 포함하지 않았다. 게임 그래픽은 Canvas 도형으로 그린다.

## 검증

`node --check game.js`, `node --check site-data.js`, `node tests/smoke.js`, `git diff --check`.

스모크 테스트는 실제 게임 코드를 Node VM에서 실행해 1200×900, 390×844, 844×390 화면에서 입구→실내→전시→출구, 두 계단 하강·상승, 높이가 있는 바닥의 터치 좌표 변환, 배치도와 줌을 검사한다. 이동 중 충돌 및 단차 건너뛰기를 검사한다. Canvas 렌더링 이미지는 별도 확인했다. 실제 Android/iPhone 브라우저 검증과 정확한 실측 평면 확인은 미완료다.
